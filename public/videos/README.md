# Videos

Drop your video here as:
  our-video.mp4     ← your CapCut/personal video (used in the story)

Recommended specs:
  - Format: MP4, H.264
  - Resolution: 1080p max (720p is fine)
  - Max size: 50MB (GitHub has a 100MB file limit)
  - Compress at: https://www.freeconvert.com/mp4-compressor

If the video is > 50MB, compress it first.
Also create a poster image (first frame or a nice still):
  our-video-poster.webp  ← shown before video plays
